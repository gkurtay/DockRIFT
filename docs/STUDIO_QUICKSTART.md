# DockRIFT Studio quick start

1. Create/activate a Python 3.10+ virtual environment.
2. Install the supplied wheel.
3. Run `dockrift studio` or `dockrift-studio`.
4. Studio opens locally at `http://127.0.0.1:8765/` by default.
5. The built-in VDR demo is ready immediately; use **Open score table** for your own long-form CSV/TSV.
6. Follow Data Lab → Pair Explorer → RRL Lab → Transferability → Seed Convergence → Validation → Export.

Uploaded files remain in the local Python process; DockRIFT Studio itself does not send them to a remote analysis service.
