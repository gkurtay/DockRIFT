# Publication integration notes

DockRIFT Studio should be described as a local-first visual workbench layered on the reusable DockRIFT numerical core, not as a separate scientific method. Software verification establishes implementation consistency; it is not independent evidence for the scientific conclusions of the accompanying manuscript.

A manuscript using this release should cite:

1. the version-specific archived DockRIFT v1.0.0 software DOI;
2. the public GitHub repository and tag `v1.0.0`; and
3. the separate machine-readable benchmark/data archive when applicable.

The Code Availability statement should identify the exact version, license, repository, DOI, and release SHA256. RRL descriptions must preserve observed-support evaluation, no extrapolation, explicit censoring, docking-score numerical units, and the distinction from binding-free-energy uncertainty.
