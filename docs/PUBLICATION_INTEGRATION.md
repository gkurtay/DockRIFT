# Publication integration notes

DockRIFT Studio should be described as a local-first visual workbench layered on the reusable DockRIFT numerical core, not as a separate scientific method. Software verification establishes implementation consistency; it is not independent evidence for the scientific conclusions of the accompanying manuscript.

A manuscript using this release should cite:

1. the version-specific archived DockRIFT v1.0.0 software DOI: `10.5281/zenodo.22104761`;
2. the public GitHub repository and tag `v1.0.0`; and
3. the separate machine-readable benchmark/data archive when applicable.

The exact tagged source for DockRIFT v1.0.0 is commit `a9aa733b45efa5d4eacb23ab6fb81b489b04c5c3`.

Canonical release artifact SHA256 values are:

- `dockrift-1.0.0-py3-none-any.whl`: `344fdd25f5f4161a3910cb56f9e7d2ee1e26e18df218ca473fe035e8194741a5`;
- `dockrift-1.0.0.tar.gz`: `857ac6b02087114bcf4bbedf8a039190855b0ed21ad2aac22e8666e7632be41a`.

## Code Availability statement

DockRIFT v1.0.0 is openly available under the MIT License from the public GitHub repository at `https://github.com/gkurtay/DockRIFT` (release tag `v1.0.0`; tagged source commit `a9aa733b45efa5d4eacb23ab6fb81b489b04c5c3`) and is archived on Zenodo with the version-specific DOI `10.5281/zenodo.22104761`. The release wheel and source distribution are accompanied by SHA256 checksums in the GitHub release assets.

RRL descriptions must preserve observed-support evaluation, no extrapolation, explicit censoring, docking-score numerical units, and the distinction from binding-free-energy uncertainty.
