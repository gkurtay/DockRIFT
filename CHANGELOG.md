# Changelog

All notable changes to DockRIFT are documented here.

## 1.0.0 — 2026-08-26

First public release.

- Released the reusable rank-transfer numerical core and custom local-first DockRIFT Studio.
- Added audited CSV/TSV ingestion, balanced-design QC, receptor×seed coverage, and SHA256 provenance.
- Added Spearman/Kendall transfer metrics, exact inversion, rank displacement, Top-k survival/Jaccard, and receptor-versus-seed attribution.
- Added directional observed-support RRL, conservative pair propagation, explicit censoring, α sensitivity, held-out diagnostics, ligand-universe sensitivity, and ligand-identity bootstrap.
- Added receptor-ensemble and seed-convergence views, activity-label diagnostics, ligand traces, and Vina/Vinardo cross-scoring comparison.
- Added manifest-driven PDBQT mode-1 score extraction and freeze/verify CLI commands.
- Added packaged VDR regression data, automated tests, API smoke evidence, and reproducibility ZIP export.
- Finalized MIT licensing, citation metadata, Zenodo metadata, GitHub Actions testing, and release documentation.
