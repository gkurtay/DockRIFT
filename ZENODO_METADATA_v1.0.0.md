**Description:**

DockRIFT is an open-source Python toolkit and local-first visual workbench for separating within-receptor stochastic repeatability from receptor-to-receptor rank transferability in molecular docking. It implements Spearman and Kendall rank transfer, exact pairwise inversion, rank displacement, Top-k stability, receptor-versus-seed attribution, and an observed-support Rank Resolution Limit with directional analysis and explicit censoring. The release includes command-line and Studio interfaces, tests, packaged demo data, documentation, and reproducibility/provenance exports. RRL values are conditional rank-stability thresholds in the numerical units of the supplied score and are not binding-free-energy error estimates.
